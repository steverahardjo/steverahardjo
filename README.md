## How I work

- **The artifact is the interface.** Slides as HTML, configs as YAML, resumes as Typst — anything an agent can edit and I can diff.
- **Reviewability over magic.** If I can't see what the model did, I don't trust it in production.
- **Ship the boring parts too.** Install scripts, release binaries, docs — the last 10% is the tool.
